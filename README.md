# Jellyfin Loudness Exporter

Exports Jellyfin audio loudness gain metadata to a portable JSON file for offline use (for example by a music player that mirrors the same relative folder tree).

This repository is public and currently empty of implementation on `main`. Development happens on feature branches. See the latest feature branch for work in progress.
